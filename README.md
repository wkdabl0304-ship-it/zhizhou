# 知舟 Zhizhou

让企业知识触手可及，让日常工作始于一句话。

**面向企业内部非技术人员的云端 AI 工作空间：通过对话读写文件、查询企业文档，让智能体协助完成日常工作。**

知舟可以理解为加入了企业共享知识库和权限管理的云端 Codex：提供类似 ChatGPT 的 Web 对话界面，智能体在服务器的工作环境中处理文件，并通过云端 RAG（检索增强生成）查找企业资料。员工无需编程，即可使用自然语言描述需求。

> 项目正在开发中，本 README 展示产品蓝图，以下主要功能为规划目标。当前已实现异步 SSE 后端聊天接口与智能体示例，采用青蓝水墨品牌的前端（统一 Logo、公共组件与明暗主题）已实现基础流式回复界面，后端新增思考与工具过程事件待前端适配；文件处理、知识检索和权限管理尚未实现。

## 主要功能

- **Web 对话**：提供类似 ChatGPT 的交互界面，在浏览器中向智能体提问、发起任务。
- **文件读写**：通过自然语言让智能体在服务器工作环境中读取、创建和修改文件，无需在本地配置开发环境。
- **共享文档问答**：企业文档统一存放在云端，通过向量检索找到相关内容，让智能体结合内部资料回答问题。
- **权限管理**：支持部门之间的数据隔离，也支持文档全员共享；文件访问和知识库检索遵循对应权限。

## 适用场景

- 查询公司制度、业务资料和部门文档。
- 让智能体阅读文件、整理内容、起草或修改文档。
- 在部门内部共享知识，或将通用资料开放给全体员工。

## 技术方案

- **前端**：Vue 3、TypeScript 与 Vite，使用 Reka UI 构建交互基础和自定义样式；已实现基础 POST SSE 回复展示，后端新增过程事件尚待适配；界面支持 Markdown 富文本、代码高亮与复制，并处理流中断；详细展示能力见[前端说明](frontend/README.md#页面与聊天边界)，文件操作界面为后续规划。
- **后端**：Python 与 FastAPI，已实现含思考与工具执行过程的异步 SSE 聊天和 PostgreSQL checkpoint，支持同会话串行、不同会话并发；文件处理、知识检索与权限管理为后续规划。
- **部署**：Docker Compose，在服务器上容器化部署工作环境和知识库相关服务。

## 部署与启动

计划由管理员通过 Docker Compose 统一部署，员工通过浏览器访问。后端 `POST /api/chat` 使用异步 SSE，使用 DeepSeek 和 PostgreSQL 保存对话状态，支持多轮对话及客户端断开取消。接口协议与中断后的保存边界见[后端说明](backend/README.md#启动与聊天接口)。前端只适配基础回复事件，尚未接入新增过程事件，当前收到新事件会报协议错误；过程展示需后续适配，开发服务器将 `/api` 代理到后端，生产反向代理需关闭 SSE 缓冲。前端每次加载页面随机生成临时会话标识，不恢复后端历史；这只是跑通聊天的临时方案，后续会重构会话管理，具体行为见[前端开发说明](frontend/README.md#页面与聊天边界)。[开发 Compose 配置](docker-compose-dev.yml)目前仅提供 PostgreSQL，尚未包含前后端服务或完整生产部署。
