# 知舟 Zhizhou

让企业知识触手可及，让日常工作始于一句话。

**面向企业内部非技术人员的云端 AI 工作空间：通过对话读写文件、查询企业文档，让智能体协助完成日常工作。**

知舟可以理解为加入了企业共享知识库和权限管理的云端 Codex：提供类似 ChatGPT 的 Web 对话界面，智能体在服务器的工作环境中处理文件，并通过云端 RAG（检索增强生成）查找企业资料。员工无需编程，即可使用自然语言描述需求。

> 项目正在开发中，本 README 展示产品蓝图，以下主要功能为规划目标。当前已实现最小后端聊天接口与智能体示例，以及采用青蓝水墨品牌的前端静态聊天原型（统一 Logo、公共组件、明暗主题与演示会话）；前后端尚未联通，文件处理、知识检索和权限管理尚未实现。

## 主要功能

- **Web 对话**：提供类似 ChatGPT 的交互界面，在浏览器中向智能体提问、发起任务。
- **文件读写**：通过自然语言让智能体在服务器工作环境中读取、创建和修改文件，无需在本地配置开发环境。
- **共享文档问答**：企业文档统一存放在云端，通过向量检索找到相关内容，让智能体结合内部资料回答问题。
- **权限管理**：支持部门之间的数据隔离，也支持文档全员共享；文件访问和知识库检索遵循对应权限。

## 适用场景

- 查询公司制度、业务资料和部门文档。
- 让智能体阅读文件、整理内容、起草或修改文档。
- 在部门内部共享知识，或将通用资料开放给全体员工。

## 技术方案

- **前端**：Vue 3、TypeScript 与 Vite，使用 Reka UI 构建交互基础和自定义样式；当前提供浏览器中的静态聊天原型，文件操作界面为后续规划。
- **后端**：Python，承载智能体、文件处理、知识检索与权限管理。
- **部署**：Docker Compose，在服务器上容器化部署工作环境和知识库相关服务。

## 部署与启动

计划由管理员通过 Docker Compose 统一部署，员工通过浏览器访问。当前前端可独立启动并体验静态聊天原型；后端已有分层的智能体模块及最小 `POST /api/chat` 接口，API 通过分级路由统一管理，使用 DeepSeek 和 PostgreSQL 保存对话状态，支持多轮对话。前端尚未调用该接口，也不会恢复后端历史记录。[开发 Compose 配置](docker-compose-dev.yml)目前仅提供 PostgreSQL，尚未包含前后端服务或完整生产部署。
